# SmartStock — Under ₹100 Final
Scans the NSE universe using BharatStock's screener and keeps only stocks with price <= ₹100. The model uses available daily screener metrics: valuation, ROE/ROCE, revenue/profit/EPS growth, debt/equity, returns, volatility, 200-DMA position, cash flow and ownership. Results are sorted by a transparent 0-100 model score. BUY/WATCH/AVOID are model signals, not guarantees. BharatStock data is latest available EOD/daily data. Enter the API key through the ⚙ Data button; it is stored only in browser localStorage and never committed to GitHub. The free plan is limited to 50 API requests/day; a full scan may use multiple requests because the screener is paginated.
